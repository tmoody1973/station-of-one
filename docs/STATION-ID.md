# Station identity

- **Station name:** Station of One
- **Call sign:** WONE, at 1.0 FM (an invented frequency, to mark it as fictional)
- **Hourly show:** The Hourly Scroll
- **Daily debate show:** The Table, identified on air as WNCL ("W-Uncle")

## Station ID lines

Use these as written, rotating one per newscast in the open or sign-off.

1. "WONE, 1.0 FM. One station, one listener."
2. "You're listening to WYOU. Literally only you."
3. "WNCL, broadcasting to a potential audience of one."
4. "Listener-supported. Listener, singular."

## Notes

- Line 2 names a different call sign from the station's. Until that is decided, the build
  uses lines 1 and 4 in the newscast and line 3 in The Table. If WONE stays, line 2 can
  become "You're listening to WONE. Literally only you."
- None of these call signs has been checked against the FCC's call sign search. Real
  stations may hold them. Check before the demo, and keep the 1.0 FM frequency and a
  "fictional station" note on the page either way.
- No real station's name, theme or sound is used.
