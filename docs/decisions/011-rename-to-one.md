# 011 — The station is renamed ONE 1.0 FM

**Decision** — The station drops the call letters WONE and WNCL and becomes ONE 1.0 FM; The Table is "The Table on ONE".

**Why this came up** — The code reviewer for the music-station plan (Nov 27) noted that WONE-FM is believed to be a real station in Akron, Ohio. The project rule says: no real station's name, call letters, theme or look. The README only said the call signs had not been checked against the FCC database, which does not hold up in front of judges. WNCL has the same problem: real US call signs start with K or W.

**Options**
1. **Check the FCC database and keep WONE if it is free.** Cost: a manual lookup, and if it is taken, the rename anyway with less time.
2. **Rename to ONE 1.0.** No call letters at all, so no clash is possible; echoes "Station of One" and "an audience of one"; "1.0" reads as version one of a machine-run station. Cost: logo, cover, pages, voice IDs and the video end card change two days before the deadline.
3. **Rename to LONE 1.0.** Same safety. Cost: reads as "lonely", against the warm, personal idea.

**What we chose and why** — Option 2. Tarik asked for "ONE 1.0 or LONE 1.0, whichever is impactful"; Claude picked ONE for the reasons above.

**What we gave up** — The radio-style call letters that made the station sound real on air; audio already published still says "WONE" until those newscasts age off the page.

**How we'll know if this was right** — No page, feed, video or new newscast says WONE or WNCL after the next build; the ID block still reads at favicon size.
