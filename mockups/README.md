# Mockups

Markup for four screens, exported from the design canvas:

- `Main.dc.html`: front page (sticky player, lead story, The Table card, story cards,
  today's newscasts, music picks, counts, Corrections, almost made air)
- `ControlRoom.dc.html`: live view of one build, step by step, with Jev's decision log
- `Onboarding.dc.html`: three steps (beats, music taste, hours)
- `Settings.dc.html`: beats and sources, music taste, broadcast, editorial rules, connections

These files use the canvas's own runtime (`support.js`, `{{holes}}`, `<sc-for>`), so they
will not render if opened directly. Use them as reference for structure, copy, spacing and
color, and rebuild the pages as plain HTML templates. To see them rendered, open the canvas
link in `docs/LINKS.md`.

Look: white ground, near-black ink #141414, one accent #C8102E, Space Grotesk headings,
Inter body. The control room is dark (#111214). Bracketed text is placeholder content.
