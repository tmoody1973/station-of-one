The program director

How {{ st.name }} is programmed

{{ st.brief }}.

A radio station's program director decides which songs the station plays, how often, and in what order. On {{ st.name }} an agent does that job around the clock, the way a real station does it: songs sit in rotation categories, every hour follows a clock, and a weekly music meeting decides what moves. Listen to {{ st.name }}{% if last_meeting %} · the latest music meeting{% endif %}.

1Judgment and rules

Jev's judgment

Jev, a model that answers typed questions with probabilities, decides what a program director decides by ear: does a new record belong here, has a song earned more airplay, are listeners tired of it, how much energy does it have. Every answer is logged with its probability.

Code's rules

Plain code applies the station's rules: the categories and their sizes, how long a song rests between plays, the hour clocks, and the separation rules. The numbers on this page are read from the configuration the station is running.

4Separation

Before a song can fill a slot, it must pass rules that never bend:

  • No artist twice within {{ st.separation.artist_hours }} hours.
  • No two songs of {{ (st.separation.long_ms / 60000) | round | int }} minutes or longer back to back.
  • Energy (low, mid, high) never jumps by two between neighbours.

Then softer preferences choose among the songs that pass. When there aren't enough songs to honour them all, they give way in this order: era alternation first, then the mix of sung and instrumental records{% if st.type == "flagship" %}, then {{ st.name }}'s own hour shape (pairings Tarik played back to back, lower energy in the first half hour, an opener after the news and a closer at the end, a holiday record in season){% endif %}. If nothing passes the hard rules, the slot stays empty and the break runs longer; an artist is never repeated to fill it.{% if holiday and st.type != "flagship" %} Holiday records play only from {{ holiday }}.{% endif %}

5The music meeting

Once a week (daily in a station's first week) the program director holds a music meeting. Jev is asked, song by song: should this new record join the rotation; has this song earned more airplay; are listeners tired of this one. Code acts only on clear answers: a probability of {{ n.add }} or more.{% if st.meeting and st.meeting.burn %} A song in the top category for {{ n.burn_days }} days steps down.{% endif %} No category changes more than {{ n.churn }}% of its songs in one meeting, so the station's sound shifts gradually.

6Where songs come from

The agent reads the station's feeds{% if st.feeds %} ({{ st.feeds | length }} music sites and communities){% endif %}, pulls out the records each item names, and Jev rates each one against the station's brief; finds rated {{ n.fit_floor }} or more can go to the music meeting. Each record is matched on Apple Music; a match under {{ (n.match * 100) | round | int }}% confidence is held for a person to check, and originals are preferred over remasters, live takes and edits.{% if st.type == "flagship" %} {{ st.name }} also draws on its own library: thirteen years of Rhythm Lab Radio playlists, where each track starts in the category its play count earned.{% endif %}{% if styles %} {{ st.name }} starts from the jazz in Rhythm Lab Radio's library, each record filed under its style and the category its plays earned. At each music meeting the agent also checks the station's artists for records released in the last {{ n.recent_days }} days, and fills thin styles with well-known recordings by their artists. Jev names each new record's style; a record Jev calls not jazz is never added.{% endif %}

7Breaks, IDs and news

The clock reserves time for station IDs ({{ (n.spoken.id / 1000) | int }} seconds), breaks ({{ (n.spoken["break"] / 1000) | int }} seconds), {% if half %}a tease at :30 and {% endif %}a back-announce before the top of the hour{% if st.news %}, plus the hourly newscast at :00 from {{ n.news_hours }}{% endif %}.

{{ st.name }} has its own host{% if st.host %}, a synthetic voice (Gemini's {{ st.host.voice }}){% endif %}, different from the newsreaders. Every few songs the host back-announces what played, gives one fact about it and says where the agent found the record, then teases what's next. Every fact must cite a source or it's cut: the facts come from a web search with citations (Perplexity), Apple Music and the post where the record was found, and Jev checks each script; one that says more than its facts is replaced by a plain back-announce. The words and their sources are listed in the playlist. In your player, the host and the news play between songs, never over a song; anything not yet voiced is skipped.

8What a model never does

A language model never picks the next song.
